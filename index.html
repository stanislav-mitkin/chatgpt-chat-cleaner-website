How it works

Five steps to a clean slate

  1. 1Open chatgpt.com in Chrome
  2. 2Click "Select chats" or press Ctrl+Shift+K
  3. 3Click conversations to toggle, or press Ctrl+A to select all
  4. 4Press Delete — then press again to confirm
  5. 5Done — selected chats are deleted instantly

FAQ

Frequently asked questions

Can you delete multiple ChatGPT conversations at once?

ChatGPT has no built-in bulk delete — you can only remove one conversation at a time from the sidebar. ChatGPT Chat Cleaner adds that missing feature: select any number of conversations and delete them all in a single action.

How do I bulk delete ChatGPT history?

Install ChatGPT Chat Cleaner from the Chrome Web Store. On chatgpt.com, press Ctrl+Shift+K (or ⌘⇧K on Mac) to enter selection mode, click conversations or press Ctrl+A to select all, then press Delete twice to confirm. The extension processes all deletions automatically.

How is this different from ChatGPT's built-in "Delete all chats" option?

ChatGPT's built-in option removes every conversation with no way to choose which ones. ChatGPT Chat Cleaner lets you select exactly which conversations to delete — useful when you want to keep some chats but clean up the rest.

Does ChatGPT save all my conversations?

Yes. By default ChatGPT stores every conversation indefinitely unless you delete them or disable history in Settings → Data controls. ChatGPT Chat Cleaner makes periodic cleanup fast — select and delete months of old chats in seconds.

Is ChatGPT Chat Cleaner safe to use?

Yes. The extension uses your existing ChatGPT login session and ChatGPT's own API — no data is ever sent to a third-party server. It requires only one browser permission: access to chatgpt.com. The source code is open on GitHub.

Does it work on Mac?

Yes. Use ⌘⇧K to toggle selection mode and ⌘A to select all conversations. The extension works in Chrome on both macOS and Windows.

Does it work with ChatGPT Plus, Team, or Enterprise?

Yes. ChatGPT Chat Cleaner works with all ChatGPT plans — Free, Plus, Team, and Enterprise — as long as you're using Google Chrome.

Will deleting conversations affect my ChatGPT account?

No. Deleting conversations only removes them from your chat history. Your ChatGPT subscription, custom instructions, and account settings are completely unaffected. A double-confirm step (press Delete twice) prevents accidental deletions.

Is ChatGPT Chat Cleaner really free?

Yes — completely free with no usage limits, no sign-up required, and no paid tier. The extension is open source and always will be.

How do I delete all ChatGPT history on iPhone or Android?

ChatGPT Chat Cleaner is a Chrome extension and requires a desktop browser. On mobile the fastest option is ChatGPT's built-in Settings → Data controls → Delete all chats. For selective bulk deletion, open chatgpt.com in Chrome on a desktop and use the extension.
